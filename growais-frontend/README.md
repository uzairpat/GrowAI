# GrowAIs Phase 1 — Public Web Pages

Next.js starter for the GrowAIs public-facing phase.

## Pages
- `/` — Home
- `/how-it-works` — How It Works
- `/for-schools` — For Schools
- `/about` — About
- `/login` — Login
- `/signup` — Sign Up

## Run
Open this folder in VS Code, then in the terminal:

```bash
npm install
npm run dev
```

Open the local URL shown by Next.js.

## Assets
The supplied GrowAIs artwork is in:

`public/assets/`

The home page is already wired to the supplied character, city, landscape and logo assets.
